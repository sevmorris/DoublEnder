**New**
- **DoublEnder updates itself.** The update prompt now offers **Update and Relaunch**. DoublEnder downloads the new version, checks that it's a signed release, replaces itself and reopens, with no disk image to open or app to drag. This starts with the update after this one: to get 2.8.0, download it as usual.
- **An update never interrupts a recording.** If you start an update during a take, it downloads and waits for the take to finish before relaunching.

**Changed**
- **No update prompt during a take.** The check at launch could answer just after you pressed RECORD and put a prompt on top of the recording. It now stays quiet, and the next launch offers the update.
- **If DoublEnder can't update itself, it says why.** A copy running from the disk image, or one you don't have permission to change, still offers **Download**, with the reason. So does any update that fails, and the installed app is left as it was.

**Developer**
- `SelfUpdater` needs no update feed or new key: it relies on the Developer ID signature that release DMGs and apps already carry. The DMG's signature is checked before it's mounted. The app inside must match this build's bundle identifier and team, be newer than the installed version, and run on this Mac's macOS and processor. See "SelfUpdater — installing an update" in the Theory of Operation.
