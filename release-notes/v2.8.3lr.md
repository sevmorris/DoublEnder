**[App Page](https://sevmorris.github.io/DoublEnder/)**

Nothing changes in how DoublEnder records. This release comes out alongside DoublEnder Cloud 2.8.3cr, whose updates now install before it opens.

**Developer**
- The release script no longer deletes old release pages when it can't confirm which ones to keep. It used to treat a failed lookup as "nothing to protect" and could remove the last release for an older macOS.
- The shared-files check compares against Transcoder, the newest sibling app.
- Quitting before the recorder window exists no longer builds the recorder just to ask whether it is recording.
