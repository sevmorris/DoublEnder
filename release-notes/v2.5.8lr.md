**Changed**
- Nothing changes in how DoublEnder records. This release keeps DoublEnder and DoublEnder Cloud on the same version; its work is for the Cloud session monitor.

**Developer**
- The engine records why it ended a take and counts a take's interruptions. `SessionDiagnostics` describes the Mac, the input and the last take for the Cloud heartbeat, and 14 new tests hold it to its privacy rules. The Local build compiles it but never sends it.
- `release.sh` checks the Cloud overlay's repo before building: clean, on main, and in sync with its remote.
- Barkeep joins the sibling apps whose shared files `check-shared.sh` compares.
