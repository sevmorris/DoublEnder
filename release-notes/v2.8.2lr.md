**[App Page](https://sevmorris.github.io/DoublEnder/)**

**Changed**
- **Help explains what DoublEnder may tell you while you record.** A new section covers the no-voice pop-up, the Microphone disconnected alert, and the prompt that appears when you plug in a USB audio device.
- **Help says which settings DoublEnder remembers.** The format you pick stays picked. The filename and notes start empty each time DoublEnder opens.

**Fixed**
- **Mistakes in Help.** The gear sits to the right of the level meter, not the record button, and the list of apps that play your file no longer names one that doesn't exist. ⌘W is listed next to ⌘Q, since both ask before quitting during a recording.

**Developer**
- The Theory of Operation catches up with `release.sh` (the test step, the main-only check, the minimum-macOS footer, and the pruning rule that keeps the last release for each older macOS) and with the update checker's minimum-macOS gate. New sections cover the Cloud name prompt, the RETRY UPLOAD card and a table of what persists across launches, and the HTML manual gains the input fallback after a disconnect between takes.
- The README and the app page describe the no-voice warning, input changes and the disk space guard, and the screenshots show 2.8.1.
- An unused "Start recording?" prompt, left from the withdrawn auto-record countdown, is gone.
