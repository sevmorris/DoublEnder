**[App Page](https://sevmorris.github.io/DoublEnder/)**

A release for DoublEnder Cloud's one-time guests. Nothing changes in DoublEnder itself.

**DoublEnder Cloud**
- **A copy you kept now tells you about new versions.** A One-Time Guest copy installs no update by itself. One you kept with **Keep & Quit** used to stay on its version for good, without ever saying a newer one was out. It now checks when it opens and tells you when there is one. It never asks during a recording, and it installs the update only if you choose to.
- **An uninstall that doesn't work now says so.** If DoublEnder Cloud can't move itself to the Trash when you quit (in your Applications folder on an account that isn't an administrator, say), it now tells you and offers to show you where it is. It used to quit as if it had worked.
- **Uninstalling leaves less behind.** DoublEnder Cloud's own folder in Application Support now goes with it. It stays if another copy of DoublEnder Cloud is installed on the Mac, because that copy uses it too.
- **Return no longer uninstalls.** In the question at quit, pressing Return used to choose Uninstall. Now you click the choice you want; Escape still keeps the app.
- **Fewer hosts asked "Host or Guest?" after updating.** A copy that has already updated itself is now recognised as a host's.

**Developer**
- Guest copies run `UpdateCoordinator.checkForUpdates(silent: true)` after launch.
- `GuestUninstall.perform` returns an `Outcome` (`kept`, `removed(clearedSettings:)`, `notRemoved(URL)`). It trashes the Application Support folder and clears the defaults only once the app is in the Trash, and only when no other installed copy shares them.
- `storedOrInferredMode` counts update history as a host's.
- The Theory of Operation has a new section, "Host and guest copies".
