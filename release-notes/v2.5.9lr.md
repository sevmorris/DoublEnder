**Fixed**
- **The record button looks the same on every Mac.** Its label used whichever of a few fonts the Mac happened to have installed, so PRESS TO RECORD looked different from one Mac to the next, and on macOS 15 the wider font it found there cut off the first and last letters. DoublEnder now ships its own font for the button, Saira, so every Mac draws it the same way.

**Developer**
- Saira Regular (SIL Open Font License 1.1) is bundled and registered at launch alongside DSEG7, and its licence ships in the app. `panelFont` no longer looks for installed fonts, the label's vertical nudge, which only suited Eurostile, is gone, and so is the unused `handelFont`.
