**[App Page](https://sevmorris.github.io/DoublEnder/)**

**Fixed**
- **The app keeps its notarization once it is out of the disk image.** Only the disk image was stapled, so the copy dragged into Applications — the only one anyone runs — carried no ticket of its own, and Gatekeeper had to ask Apple about it on first launch, which needs a working network. The app is now notarized and stapled by itself before the image is built around it, and the release checks the ticket on the copy that ships.
- **The disk image is signed.** Only the app inside it was, so `spctl` reported the download itself as having "no usable signature", even with a valid ticket stapled to it.

**Developer**
- **Running the tests no longer touches your settings.** The tests run inside DoublEnder, so a test run started all of it. That cleared the session's custom filename, asked for the microphone, recorded connected USB devices, scanned for unfinished recordings and checked for updates. One test also wrote a name over the remembered guest name before putting it back. Now a test run starts the app with no window, and a test's settings go to a scratch store in the temporary folder.
- The tests run in CI.
- `release.sh` no longer bumps the deprecated Homebrew cask: the app updates itself from GitHub. It requires curated release notes, leaves no version bump behind when interrupted, and says when a locked screen rather than a missing profile stops notarization.
- The project site is served as written, without Jekyll.
- `scripts/check-shared.sh` looks for the sibling repos beside the main checkout, so a release made from a worktree compares the shared files. Before, it compared none and still reported them in sync.
