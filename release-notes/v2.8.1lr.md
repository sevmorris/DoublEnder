**[App Page](https://sevmorris.github.io/DoublEnder/)**

This is the first release DoublEnder 2.8.0 can install by itself: choose **Update and Relaunch** when it offers the update.

**Changed**
- **The level meter hears every input of an interface with many.** Some audio interfaces give macOS many inputs without saying which is which: the Neumann MT 48 gives 32. The recording takes in all of them, but the level meter and the no-voice warning listened to the first one only. A mic plugged into the second input recorded normally while the meter stayed dark, and after 2 minutes the no-voice warning appeared. The meter and the warning now hear every input, as the recording does, and show anything else the interface sends on its other inputs too.
- **An update that had to wait asks before relaunching.** If you start an update during a recording, DoublEnder downloads it and waits for the take to finish, as before. Then it asks before relaunching, because a relaunch would clear the confirmation on screen. **Not Now** leaves the update for later. This applies to updates from this version on.

**Developer**
- `PCMSidecar.writerMixGains` weights each channel 1 when a source has three or more channels and no channel layout, which is how AVAssetWriter mixes them to the mono file. That was measured from 3 to 32 channels, interleaved and planar. `PCMSidecarTests` writes 3, 4, 8 and 32 such channels through the writer on every CI run. See "The mono mix" in the Theory of Operation.
- `SelfUpdater.swift` is shared verbatim with the sibling apps, and `scripts/check-shared.sh` compares it. The prompt, the progress window and the relaunch moved into it, so `UpdateChecker` only fills in a `SelfUpdatePrompt`.
